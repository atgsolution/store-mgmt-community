# Security Policy / Chính sách bảo mật

## Supported versions / Phiên bản được hỗ trợ

Security fixes target the latest stable release. The `main` branch may contain unreleased changes and is not a deployment support channel.

Bản vá bảo mật được phát hành cho phiên bản ổn định mới nhất. Nhánh `main` có thể chứa thay đổi chưa phát hành và không phải kênh hỗ trợ triển khai.

## Reporting a vulnerability / Báo cáo lỗ hổng

Do not disclose vulnerabilities in public issues, discussions, or pull requests. Use [GitHub private vulnerability reporting](https://github.com/atgsolution/store-mgmt-community/security/advisories/new).

Không công bố lỗ hổng qua issue, discussion hoặc pull request. Hãy dùng [kênh báo cáo bảo mật riêng của GitHub](https://github.com/atgsolution/store-mgmt-community/security/advisories/new).

Include:

- affected version or commit;
- deployment context;
- reproduction steps or proof of concept;
- expected security impact;
- suggested mitigation, if available.

Vui lòng cung cấp phiên bản hoặc commit bị ảnh hưởng, môi trường triển khai, cách tái hiện, mức độ ảnh hưởng và phương án giảm thiểu nếu có.

The maintainers will coordinate validation, remediation, and disclosure through the private advisory. Please allow a reasonable remediation period before public disclosure.

Nhóm duy trì sẽ phối hợp xác minh, sửa lỗi và công bố qua security advisory. Vui lòng dành thời gian hợp lý để xử lý trước khi công bố rộng rãi.
