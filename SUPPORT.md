# Support / Hỗ trợ

- Usage and deployment questions: open a GitHub Discussion.
- Reproducible product defects: use the bug report form.
- Feature proposals: use the feature request form.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md), never a public issue.

- Câu hỏi sử dụng và triển khai: tạo GitHub Discussion.
- Lỗi có thể tái hiện: dùng biểu mẫu báo lỗi.
- Đề xuất tính năng: dùng biểu mẫu đề xuất.
- Lỗ hổng bảo mật: thực hiện theo [SECURITY.md](SECURITY.md), không tạo issue công khai.
